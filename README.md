# C# Övning 1 – Personalregister

## Publicera projektet med Git

1. Klicka på **Add to Source Control** nere i högra hörnet i Visual Studio och välj **Git**.  
   Alternativt: gå till **Git → Create Git Repository**.
2. **Avmarkera** checkboxen **Private**.
3. Klicka på **Create and Publish**.
4. Kontrollera i webbläsaren att repositoriet har skapats och att alla filer finns med.
5. Om filer saknas, öppna **Git Changes** i Visual Studio.
6. Skriv ett commit-meddelande och klicka på **Commit**.
7. Klicka därefter på **Push** (pilen uppåt).  
   Alternativt kan du använda **Sync** (två pilar i en cirkel).
8. Kontrollera återigen repositoriet i webbläsaren.
9. Klart!

---

## Bakgrund

Ett litet företag i restaurangbranschen kontaktar dig för att utveckla ett enkelt personalregister.

De har två krav:

1. Registret ska kunna ta emot och lagra anställda med **namn** och **lön** via inmatning i konsolen. Ingen persistent lagring krävs.
2. Programmet ska kunna skriva ut personalregistret i konsolen.
